How to install JavaScript error reporting

1

Add the SDK

Install the JavaScript SDK for your framework or vanilla setup.

npm install @error-tracker/js
2

Initialize

Add your project configuration. Replace the DSN with the one from your project settings.

import { init } from '@error-tracker/js';

init({
  dsn: 'https://xxx@o1.error-tracker.com/123',
});
3

Verify

Trigger a test error to confirm events are coming in.

throw new Error('Test error');
